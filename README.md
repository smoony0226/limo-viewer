# LIMO Pro 치수 뷰어

Autorace2026 대회 차량 WeGo LIMO Pro의 치수와 센서 배치를 3D로 보는 페이지입니다.

- 페이지: https://smoony0226.github.io/limo-viewer/
- 위키 공식 스펙은 확정값, 점선으로 표시된 값(카메라·LiDAR 높이 등)은 실측 전 추정값입니다.
- 주소 옵션: `?view=iso|front|side|top`, `&lane=1` (차선 500mm), `&judge=1` (앞바퀴 판정 기준점), `&dims=0`
